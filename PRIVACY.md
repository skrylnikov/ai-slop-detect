# Privacy Policy

AI Slop Labels is a browser extension for community labels on articles.

## Data we process

When the extension is used, it sends the supported article identifier to `ai-slop-detect.dskr.dev` to load community totals and votes. When a user submits a vote, the selected label and optional comment are sent to the same service. The extension stores the login token and the local display preference in the browser's local extension storage.

GitHub login is optional. If used, GitHub provides the account identity needed to associate votes with the user. The service does not receive or store the GitHub password.

## Use and retention

Article identifiers, votes, comments, and the associated account identity are used only to provide community labels, prevent unauthorised vote changes, and operate the service. We do not sell this data or use it for advertising. Users can delete their own vote from the extension panel.
