## Purpose

Подтверждает владельца голосов через GitHub и защищает изменение данных собственными отзываемыми сессиями сервиса.

## ADDED Requirements

### Requirement: GitHub sign-in
Система SHALL поддерживать вход только через GitHub и определять пользователя по стабильному ID провайдера, а не по изменяемому логину. Вход SHALL работать из popup и панели в Chromium и Firefox и не требовать доступа к репозиториям. OAuth-секреты и токены провайдера SHALL не передаваться странице Хабра или content script.

#### Scenario: Successful login and returning user
- **WHEN** пользователь проходит вход, затем повторно входит после смены логина GitHub
- **THEN** открывается сессия того же пользователя и сохраняется принадлежность его голосов

#### Scenario: Cancellation or provider failure
- **WHEN** пользователь отменяет вход либо провайдер возвращает ошибку
- **THEN** сессия не создаётся, показано понятное сообщение и вход можно повторить

### Requirement: Bound authorization flow
Система SHALL связывать OAuth-вход с инициировавшим экземпляром расширения, проверять state и PKCE, разрешать только настроенные адреса возврата и отклонять просроченные или повторные коды обмена. GitHub client secret SHALL оставаться на backend.

#### Scenario: Forged or repeated callback
- **WHEN** callback имеет неверный state, PKCE, адрес возврата или повторно использованный код
- **THEN** запрос отклоняется без выдачи сессии

### Requirement: Session authorization and revocation
Система SHALL выдавать ограниченные по сроку собственные сессии и получать владельца голосования только из проверенной сессии. Анонимные, просроченные и отозванные сессии SHALL не позволять запись. Выход SHALL отзывать текущую сессию сервера и очищать её в расширении. Удалённые или заблокированные сервером сессии SHALL требовать нового входа.

#### Scenario: Ownership enforcement
- **WHEN** клиент пытается изменить чужой голос, передав чужой user ID
- **THEN** чужой голос остаётся неизменным; клиент не может назначить владельца записи

#### Scenario: Logout or expiry
- **WHEN** пользователь выходит либо срок сессии истекает
- **THEN** последующая запись отклоняется с 401, а публичное чтение остаётся доступным
